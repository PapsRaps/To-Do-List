# To-Do List

A simple and customizable to-do list application that helps users organize their tasks into projects, track their progress, and manage their daily activities.

## How to Use

1. Open the application.
2. Create a project to organize your tasks.
3. Select a project from the sidebar to view its tasks.
4. Add tasks and provide their details, including due dates.
5. Mark tasks as completed using the checkbox.
6. Use the task filters to view all, active, or completed tasks.
7. Edit or delete projects using the project dropdown menu.
8. Change the website's appearance using the theme switcher.
